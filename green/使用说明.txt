# Marmoset Toolbag 5 简体中文汉化补丁

适用于 **Marmoset Toolbag 5.0.3.2（build 5032）**，其他版本未测试。

汉化内容：菜单、面板标题、按钮、下拉选项、工具提示与说明文字。
界面字体使用软件自带的 `notosans_chinese.slug`，无需额外安装中文字体。

---

## 一、安装包版（推荐）

运行 **`Toolbag5_汉化补丁.exe`**。

1. 双击运行，程序会自动检测 Toolbag 5 的安装目录（读不到时可手动点「浏览…」选择）。
2. 点「开始安装」。若 Toolbag 正在运行，会提示关闭。
3. 安装完成后可直接启动软件查看中文界面。

**卸载方式**（任选其一）：

- 打开「设置 → 应用 → 已安装的应用」，找到「Marmoset Toolbag 5 简体中文语言包」卸载；
- 或再次运行 `Toolbag5_汉化补丁.exe`，加参数 `/uninstall`；
- 卸载后 `toolbag.exe` 与 `english.txt` 会还原为原始英文版。

安装包支持静默安装，方便批量部署：

```
Toolbag5_汉化补丁.exe /S            :: 静默安装
Toolbag5_汉化补丁.exe /uninstall /S :: 静默卸载
```

安装日志位于 `C:\ProgramData\ToolbagZh\setup.log`，出问题时可以查看。

## 二、绿色版（免安装）

解压后运行 **`安装.bat`**，脚本会：

1. 自动定位 Toolbag 5 安装目录；
2. 把原版 `toolbag.exe` 与 `data\text\english.txt` 备份到 `backup` 子目录；
3. 按 `dist\patch.json` 里的补丁数据就地修改 `toolbag.exe`，并用 SHA256 校验结果。

绿色版**不含游戏本体文件**，只带补丁数据（`dist\patch.json` 与汉化后的 `english.txt`），
所以体积很小（约 110 KB）。补丁在安装时现场写入，效果与安装包版完全一致。

其他脚本：

| 脚本 | 作用 |
| --- | --- |
| `安装.bat` | 安装汉化（自动备份） |
| `卸载.bat` | 从备份还原英文版 |
| `切换到中文.bat` | 在中文/英文之间切换，无需重新安装 |
| `切换到英文.bat` | 同上，切回英文 |
| `查看状态.bat` | 显示当前安装目录与语言状态 |

绿色版不写注册表，卸载只需还原备份。整个文件夹可以整体拷贝到别的机器使用。

## 三、安全说明

汉化采用**等长字节替换**：只改可执行文件里界面文字的字节内容，不改变文件大小，不修改 PE 头与节表，因此不会破坏程序结构。

少数中文译文比原文长（例如 `Scene` → `场景`），程序是按**编译期写死的字节长度**去读取这些字符串的，只改字符串本身会被截断成半个汉字。补丁因此会同时改写调用点的长度常量，保证完整显示。

- 安装前会校验目标文件的 SHA256。若你的 Toolbag 版本与补丁不匹配，程序会明确提示并让你确认，不会静默写坏文件。
- 安装前自动备份原文件。备份只在确认是原版时创建，绝不会用已汉化的文件覆盖备份，所以卸载一定能还原英文。
- 写入 `toolbag.exe` 时先写临时文件再替换，中途断电或中断不会留下半个文件；写入失败会自动用备份还原。

## 四、常见问题

**界面里还有少量英文？**

工作区标签页（`Animate`、`Classic`、`Setup` 等）来自你自己的工作区配置文件名，保存在
`%LOCALAPPDATA%\Marmoset Toolbag 5\workspaces\`。想改名的话，可以在软件里重命名工作区，
或退出软件后直接重命名该目录下的 `*.json` 文件（文件名即标签名）。

**卸载后想再次汉化？**

直接重新运行安装程序或 `安装.bat` 即可，备份会复用，不会重复占用空间。

**安装后想恢复英文但备份丢了？**

可以重新安装一遍官方 Toolbag 5，或在 Steam/官网重新下载对应版本覆盖安装。
